Computer Hardware Repair

Repair laptops and desktops, upgrade parts, install systems and recover data for homes, schools and offices.

Your first step

Open an old desktop computer, name every part, put it back together and make it boot.

Summary of the work

Repair laptops and desktops, upgrade parts, install systems and recover data for homes, schools and offices.

Skills training

  • Assembling and upgrading PCs
  • Laptop screen and keyboard replacement
  • Operating system installation
  • Data backup and recovery
  • Diagnosing power and board faults

Training path, step by step

  1. First stepOpen an old desktop computer, name every part, put it back together and make it boot.
  2. Learn computer parts and safety
  3. Assemble and upgrade a desktop
  4. Install and repair systems
  5. Repair laptops with supervision
  6. Recover data and handle clients
  7. Run a repair and sales shop

Certification

Trade test where offered; NABTEB Modular Trade Certificate; a strong record of repaired devices and repeat customers.
